# Mouse Jiggler Card

Een custom Home Assistant kaart in de vorm van een computermuis. Ideaal voor het bedienen van twee bureau-gerelateerde switches en bijbehorende waardes.

## Features
- **Visueel:** Muisvorm met CSS (geen afbeeldingen nodig).
- **GUI Config:** Volledig instelbaar via de Home Assistant UI editor.
- **Linker/Rechter knop:** Bedient switches of lampen.
- **Scrollwiel zone:** Bedient `input_number` entities.
- **Palmsteun:** Twee extra actieknoppen.

## Installatie

### Via HACS (Aanbevolen)
1. Ga naar HACS > Frontend.
2. Klik op het menu (3 puntjes) rechtsboven > Custom repositories.
3. Voeg de URL van deze repository toe. Categorie: **Lovelace**.
4. Klik op "Download".

### Configuratie
Je kunt deze kaart toevoegen via het Dashboard:
1. Klik "Kaart toevoegen".
2. Zoek naar "Mouse Control Card".
3. Vul de entiteiten in via de visuele editor.
